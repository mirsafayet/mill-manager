# মিল ম্যানেজার (Mill Manager)

বাংলাদেশের রাইস মিল / মিল মেস-এর জন্য সহজ ওয়েব অ্যাপ।  
মেম্বার, জমা-উত্তোলন, মিল/চাল হিসাব, খরচ ও মাসিক রিপোর্ট সব এক জায়গায়।

## ফিচার

- অ্যাডমিন লগইন (Supabase Auth)
- মেম্বার ম্যানেজমেন্ট (যোগ / সম্পাদনা / মুছে ফেলা)
- লেনদেন: জমা, উত্তোলন, মিল/খাবার, চাল
- অটো ব্যালেন্স হিসাব
- বকেয়া (নেগেটিভ ব্যালেন্স) ট্র্যাকিং
- খরচ ম্যানেজমেন্ট
- মাসিক হিসাব
- রিপোর্ট (তারিখ রেঞ্জ)
- সার্চ ও ফিল্টার
- ড্যাশবোর্ড (মোট মেম্বার, জমা, খরচ, ব্যালেন্স)
- মোবাইল + ডেস্কটপ রেসপন্সিভ
- PWA (হোম স্ক্রিনে অ্যাড করা যায়)

## সেটআপ (৫ মিনিট)

### ১. Supabase প্রজেক্ট তৈরি
1. [supabase.com](https://supabase.com) এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন
2. নতুন প্রজেক্ট তৈরি করুন

### ২. ডাটাবেস টেবিল
1. Supabase Dashboard → **SQL Editor**
2. `supabase-schema.sql` ফাইলের পুরো কোড কপি করে রান করুন

### ৩. অ্যাডমিন ইউজার
1. **Authentication → Users → Add user**
2. ইমেইল + পাসওয়ার্ড দিয়ে একজন অ্যাডমিন তৈরি করুন  
   (বা Authentication → Providers → Email এনাবল রাখুন)

### ৪. API কী সেট করুন
1. **Settings → API** থেকে:
   - Project URL
   - `anon` `public` key
2. `config.js` ফাইল খুলে আপডেট করুন:

```js
const SUPABASE_URL = 'https://xxxxx.supabase.co';
const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
```

### ৫. চালু করুন
যেকোনো স্ট্যাটিক হোস্টিংয়ে আপলোড করুন, অথবা লোকালি:

```bash
# Python
python -m http.server 8080

# অথবা Node
npx serve .
```

ব্রাউজারে `http://localhost:8080` খুলুন এবং লগইন করুন।
